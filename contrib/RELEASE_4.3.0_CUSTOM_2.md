# MailFlow 4.3.0-custom.2

- 新增邮件验证码一键复制，支持单邮件、会话展开和应用内新邮件提醒。
- 综合中英文验证语境、输入指令、代码格式和 HTML 版式识别，支持“安全代码”、Security code、one-time PIN 等表达；过滤引用旧码、订单号和客服参考号。
- 新增可选自动复制：“设置 → 行为 → 验证码”。默认关闭，仅当前客户端和账号生效；前台已解锁时处理近期新邮件，只有唯一且高把握的候选才自动复制。
- 精简验证码区域与设置说明。
- 修复 OpenAI 新模型连接测试的 max_tokens 参数兼容问题，保留已有第三方接口兼容性。

验证码在客户端本地识别，不调用 AI。自动复制不包含手机系统通知栏、键盘自动填充或应用关闭后的后台行为。

Windows 延续未签名安装包策略；Android APK/AAB 延续原有固定签名；应用内更新来源保持 YunQue0912/mailflow。
